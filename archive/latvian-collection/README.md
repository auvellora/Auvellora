# Latvian collection (August 2026)

The six pieces from the first, Latvian version of the site. They are kept here
so nothing is lost. The site does not read this folder.

In October the site moved to English and to two Elements, Rise and Keeper
(see `src/content/elements/`). Rise reuses Svece's details and Keeper reuses
Birzs's wording.

To bring a piece back, translate it, copy it into `src/content/elements/` and
add a photo to `public/images/`.
